# Oil-Spill-Marine-Polution-Monitoring-Dashboard
An intelligent marine pollution monitoring dashboard that integrates satellite imagery and environmental data to detect, analyze, and visualize ocean contamination in real time. Oil Spills and Marine Pollution Dashboard is a geospatial monitoring and analytics platform designed to visualize and analyze coastal pollution incidents in an intuitive, map-first interface.

The dashboard tracks multiple types of marine pollution, including oil spills, plastic waste accumulation, chemical discharge, and algal blooms. Each incident is plotted on an interactive map with detailed metadata such as severity level, affected area, location, and timeline, allowing users to quickly assess environmental impact.

The system supports dynamic filtering and real-time-style updates, enabling users to explore incidents by type, severity, and region. It also provides multiple stakeholder-focused views, offering tailored insights for fishermen (fishing safety and restricted zones), government authorities (response tracking and incident status), tourism (beach safety levels), and residents (health risk indicators).

Additional features include:

* Live statistics and severity breakdowns
* Interactive charts for trend and distribution analysis
* Alert system highlighting critical incidents
* Searchable incident log with quick navigation to map locations
* Context-aware UI that adapts based on selected user perspective

Built using Leaflet.js for geospatial visualization and Chart.js for data analytics, the project emphasizes usability, clarity, and real-world applicability. It is designed as a prototype of a decision support system for environmental monitoring and coastal management.
